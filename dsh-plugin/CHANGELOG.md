# DSH 插件更新公告

## v2.2.1 2026-10-22 01:04版本：DSH 2.2.1 / Web 0.5.1 / MCP 0.5.1

新增基础富文本支持：文本框和文本视窗可显示粗体、斜体、字号及颜色标签，编辑预览、试玩和截图共用排版，标签不再作为普通文字显示或参与换行。

编辑页支持图片遮罩和羽化预览：调整参数后可直接查看矩形裁切、边缘羽化和嵌套遮罩效果，无需进入试玩；选框和控制点独立显示，便于调整被裁掉的控件。

改进文本框高度不足时的显示：按最终字号与框高保留能完整容纳的行，一行也放不下时只显示底色，减少“模拟器有字、游戏里缺字”的布局误判。

完善 AI 实机脚本同步：授权后可通过 MCP 或 Harness 完成保存、差异预览和选定脚本复制，覆盖前自动备份。（更新已绑定目录时，无需再到编辑器手动点击复制；完成后仍需在千星沙箱保存并重新试玩。）

完善控件索引校验与旧存档兼容：统一编辑器和导出的索引范围，保留旧编号、历史变更记录及脚本挂载，避免查看或导出时静默重编号导致引用断开。

本次通过 npm 发布，不单独创建 GitHub Release；界面“检查更新”暂不提示此补丁，请重新执行 npm／Harness 安装命令更新。更新后重启宿主并刷新页面。富文本为基础标签子集，遮罩沿用矩形取形，最终效果请在游戏内核对。

## 2.1.1 · 2026-10-12

本次同步更新：**DSH 2.1.1 / Web 0.4.1 / MCP 0.4.1**。

### 主要更新

- 修复客户端 GIA 导入导出的控件层序，解决部分模板导入后前后遮挡颠倒的问题。
- 新增客户端索引批量校准：填写任意模板或子控件的实际索引，可按原生导入顺序自动填写整批模板及子控件，并预览数量和索引范围。适用于同批导入、结构未增删或重排的模板。
- 完善 Lua 索引同步：支持「全量替换脚本索引」及「复制提示词给 AI」两条路径，衔接保存存档、重新载入和实机脚本更新。全量替换写前自动备份，也会修改同值的非索引内容，请检查替换结果。
- 支持 X/Y/Z 旋转编辑及 GIA 三轴保存，编辑预览、试玩和截图可显示 X/Y 压缩、侧立及背面镜像。
- 优化大批量索引提示、剪贴板不可用时的手动复制，以及窄屏布局。

### 更新与使用

更新后重启模拟器服务或 Harness，并刷新网页。遇到旧版 GIA 层序问题时，使用原始完整存档重新导出。控件索引校准后，继续完成 Lua 同步并保存存档，再更新游戏脚本。

旋转的单轴图片行为已有 PC 真机依据；混合轴和嵌套倾转仍采用模拟器策略。最终效果请在千星沙箱中试玩核对。

安装包与发布状态见 [版本公告](https://github.com/1475505/miliastra-beyond-simulator/releases/tag/npm-2026-10-12-1)。

## 2.0.11 · 2026-10-07

本次为 `dsh-plugin-beyond-simulator@2.0.11` 稳定性修复，解决主组件启动或重载时报 `webserver: duplicate prefix route "/qxqy-simulator/api"` 的问题。

### 修复内容

- 修复组件卸载时 HTTP 路由未注销的问题。同一组件重新激活或依赖服务重载后，可正常注册 API、试玩页、渲染脚本、图片和音频路由。
- 完善初始化失败回滚，清理本次已经注册的路由。
- 组件卸载时等待试玩 Worker 退出，并阻止迟到请求重新创建已卸载的会话。
- 增加生命周期回归验证，确保重启后网页与 AI 工具操作同一份工程。

该问题在只安装一份插件时也可触发，报错本身不代表重复安装。修复补齐了路由的生命周期清理。

### 安装与更新

可直接下载本 Release 附带的 `dsh-plugin-beyond-simulator-2.0.11.tgz`，通过实际使用的 Harness profile 安装。以下以 `web` profile 为例：

```sh
dsh plugin --profile web add ./dsh-plugin-beyond-simulator-2.0.11.tgz
```

npm 版本审核上线后，也可执行：

```sh
dsh plugin --profile web add dsh-plugin-beyond-simulator@2.0.11
```

更新后请从托盘完整退出 Harness，再重新启动，以清除旧进程残留的路由。保留原版 `cordis.patch.yml`，无需注释主组件的 insert。
