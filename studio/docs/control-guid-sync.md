# 修改索引后的 Lua 同步

上级：[Studio](../README.md#专题树)。批量校准顺序及适用条件见[客户端模板层序](client-template-order.md#imported-index-calibration)。

这是模拟器工作流，不是千星沙箱的自动重映射能力。`setControlGuid` 仍只修改控件和明确的模板引用；随后通过共享编辑器的「下一步：同步 Lua 索引引用」完成代码更新。

## 用户流程

1. 修改索引后，提示区立即显示「控件索引已修改 → 同步 Lua → 保存存档、更新游戏脚本」。变更详情默认折叠，避免数千行记录挡住操作。整块提示右上角可「关闭」，收起为一行「Lua 索引待同步（N 项）· 展开」入口，不修改或清除记录；再次修改索引时自动展开提醒。
2. 提供两个主选项。「全量替换脚本索引」旁常显「可能错误地替换非索引内容」。点击后直接处理所有已登记脚本，包括配置表、字符串、注释和同值的非索引内容；更新内联源码与内容一致的已有工作区 `.lua` 文件，文件型脚本读其工作区路径，写前备份。成功后清除这一轮记录并报告替换数量和备份位置；这仅表示文本替换完成，不代表语义核验通过。随后检查结果、保存完整存档、重新试玩；更新游戏文件沿用「Lua 脚本 → 实机脚本同步」。
3. 「复制提示词给 AI」先提交草稿并保存当前完整存档。提示词给出工作区、存档、脚本位置，以及获取全部映射的方法：读存档 JSON 顶层 `controlGuidChanges` 的 `oldGuid`/`newGuid`，结合 `controlAsset`/`controlId` 和时间顺序核对。源码在 `assets.scripts[].source`，文件路径在 `.path`。任何规模都不依赖界面显示的前 20 项，不向聊天塞入数千行映射。首次未保存的工程先要求选存档路径。复制后在同步区域顶部展开可选取的完整文本，并回到该区域顶部；剪贴板不可用时也能直接手动复制，无须向下滚动寻找。
4. 用户把任务粘贴给自己当前项目的 AI。AI 从指定磁盘存档重新加载，处理内联源码、源文件和生成器映射，核验后仅确认已处理记录并保存。用户点「AI 已处理，重新载入存档」，再进入实机脚本同步。编辑器没有偷偷向某个 AI 服务发送数据。

希望保留非索引数字、处理间接计算或生成器配置时，选择 AI 路径。没有未完成核对就可直接清空记录的第三个主按钮。

## 服务端容器索引校准

服务端「客户端控件容器」是真实 GIA 控件，使用同一个 `setControlGuid` 单独校准。在「UI控件-服务端」选中该容器，右侧「服务端控件索引」填写游戏导入后的实际值，再点「修改」。随后可回到「UI控件-客户端」继续批量校准，并按上面的流程同步 Lua、保存存档。服务端界面的其他客户端节点仍逐项填写。

服务端容器采用相同的范围、跨资产/脚本冲突与 revision 校验，记录 `controlGuidChanges`，保留内部 ID、层级与子控件脚本挂载；修改结果进入 JSON 和 GIA 导出。客户端模板列表的合成根不是 GIA 控件，不开放索引修改。客户端自动填充仅覆盖模板及子控件，不自动移动服务端容器或脚本编号。

旧实现同时在界面和 `setControlGuid` 中排除了所有 `server-container`，因此客户端批量区间碰到服务端容器编号时，提示先填写占用者实际索引却没有入口。用户截图中的输入为末项 `1073741853`、五个模板区间 `1073741849–1073741853`，被容器 `1073741850` 阻断。回归使用独立合成工程复现冲突，先校准容器，再完成批量填写；原项目未提供，不据此指定用户应填的服务端实际值。实现入口为 `studio/index.js`、`editor-ui/index.js`；证据范围为源码与模拟器回归（`evidence_source=observed`、运行端 `simulator`、`device_status=not_required`），不新增游戏编号分配规则。

## 全量替换边界

`control-guid-lua.js` 按旧索引的十进制文本匹配完整连续数字段，不区分语法和用途，不在更长的数字串中切出子串。逐控件组合连续变更为初值→终值，再对原源码一次性应用；支持同批占用区间重叠，不串号。运行时 ID、图片 ID 或其他参数与旧索引相同也会被替换，这是用户选择此选项时明确展示的风险。除匹配文本外保留格式及换行。

此模式不计算十六进制、科学计数法或 `50+50` 等表达式的值，不遍历工程里未登记的模块和生成器。引用由这些方式产生时应选 AI。源码与项目文件不同、文件不可读取、映射身份有歧义等事务冲突仍拒绝整轮替换，保留待处理记录。

`controlGuidChanges[].scriptSignature` 继续作为修改索引当时的源码摘要保留，供 AI 核对；全量替换针对点击时的当前源码，不要求旧存档带此字段。已经手动更新过部分代码时，同值的新编号也可能被再次当作旧编号处理，需检查结果或使用 AI 语义同步。

## 索引范围与旧数据

新填写/分配及GIA导出采用 `1073741824–1077936127`（`0x40000000–0x403FFFFF`）。范围及类型位解释来自 [PR #23](https://github.com/1475505/miliastra-beyond-simulator/pull/23) 作者报告，`evidence_source=provided_unverified`、运行端 `device`、`device_status=pending`；原始真机文件、客户端版本和截图未随MR提供，不把位段解释升级为独立确认的官方契约。

- `gia/guid.js` 集中定义新索引合法性与旧存储ID合法性。合法下界 `1073741824` 与自动分配起点不同：普通控件/脚本从 `1073741850` 起，按传入分配集合的当前最大合法编号加一，到上界明确失败，不从区间内部寻找空洞。新增控件按当前资产树收集占号；脚本按两棵资产树及已有脚本收集占号。
- 新建或缺少编号的服务端「客户端控件容器」优先用 `1073741847`，若该号在分配集合中已占用，则回退到上述递增规则。它是模拟器默认值，不是合法下界或游戏专用保留号；已有服务端编号原样保留，需要时通过上方校准入口显式修改。客户端模板列表合成根不分配编号。实现为 `nextControlGuid`，新建和 GIA 补号共用；`layout.test.mjs` 覆盖默认值、占号回退与旧号保存重载（`evidence_source=observed`、运行端 `simulator`、`device_status=not_required`）。
- 正整数旧控件/脚本ID及历史映射的两端仍可读取、JSON保存和检查。读取快照不因新增区间限制自动改掉旧ID；GIA导出遇到范围外已有ID明确失败，保留原值。没有索引的节点继续分配新区间编号。
- 控件用已有 `setControlGuid` 显式校准：一次性更新已知模板引用，记录 `controlGuidChanges`，Lua保留原文等待语义同步。脚本旧ID和GenericSlot挂载也原样保留；旧脚本索引修复需结合真实脚本映射及代码引用处理，当前没有脚本索引校准UI，不能把自动分配新号当成完整迁移。
- 回归：`control-guid.test.mjs` / `control-guid-autofill.test.mjs` 覆盖上下界、分配耗尽、旧ID/记录/挂载保留、导出拒绝原子性、显式校准、重叠置换及外部脚本碰撞；`gia-reference.test.mjs` 用独立wire验证脚本GIA范围。读取旧值不得改变引用、挂载或revision。

## 宿主与文件事务

共享 Host 提供两个 patch：

```json
{ "op": "previewControlGuidSync", "expectedRevision": 15 }
{ "op": "syncControlGuidReferences", "planId": "预览返回的 id", "expectedRevision": 15 }
```

预览返回快照附加的 `controlGuidSyncPreview`；应用返回 `controlGuidSyncResult`。编辑器一次点击顺序完成预检与应用，不额外要求确认。Web、DSH、MCP 共用 Controller；纯 `createStudio()` 不提供文件同步操作。计划只在当前进程有效。AI 默认走语义同步，只有用户明确选择全量文本替换时才用这两个操作替代语义判断。

应用时重验完整存档与项目文件指纹，在工作区 `.qxqy-guid-sync-backups/<计划ID>/` 保存原存档、被改文件原内容，再替换文件并提交经过验证的新存档状态。错误时回滚已写文件，保留待处理记录；回滚失败明确返回备份位置。路径使用 Host 工作区边界，游戏目录不属于此步骤。不创建缺失的源文件，不覆盖与内联源码不同的源文件。尚未保存的新存档仍通过现有保存入口落盘。

## 验证

证据范围为 Windows / Node22 / Edge，`observed / simulator / not_required`：

- `studio/test/control-guid-sync.test.mjs`：重叠映射与真实 Lua 实例化、连续校准、备份/保存/重载、预览不写、磁盘分歧与过期计划、旧记录/文件型源码，以及配置表/字符串/注释/非索引数字的全量替换。
- `studio/test/control-guid.test.mjs` / `control-guid-autofill.test.mjs`：服务端容器单项校准、冲突/非法输入原子性、JSON 持久化和 GIA 导出；`web/test/control-guid-browser.test.mjs`：服务端容器占号阻断客户端批量填写，经真实索引输入框修改容器后重试并保存，两类变更记录均保留。
- 浏览器观察覆盖全量替换与AI两条路径、风险说明、完整映射读取、剪贴板回退和存档重载；不表示当前存在对应的长期浏览器用例。
- 现有索引/GIA、脚本复制测试继续执行。这些测试不代表游戏内新 Lua 已通过。
