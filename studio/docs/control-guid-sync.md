# 修改索引后的 Lua 同步（2026-10-12）

这是模拟器工作流，不是千星沙箱的自动重映射能力。`setControlGuid` 仍只修改控件和明确的模板引用；随后通过共享编辑器的「下一步：同步 Lua 索引引用」完成代码更新。

## 用户流程

1. 修改索引后，提示区立即显示「控件索引已修改 → 同步 Lua → 保存存档、更新游戏脚本」。变更详情默认折叠，避免数千行记录挡住操作。整块提示右上角可「关闭」，收起为一行「Lua 索引待同步（N 项）· 展开」入口，不修改或清除记录；再次修改索引时自动展开提醒。
2. 提供两个主选项。「全量替换脚本索引」旁常显「可能错误地替换非索引内容」。点击后直接处理所有已登记脚本，包括配置表、字符串、注释和同值的非索引内容；更新内联源码与内容一致的已有工作区 `.lua` 文件，文件型脚本读其工作区路径，写前备份。成功后清除这一轮记录并报告替换数量和备份位置；这仅表示文本替换完成，不代表语义核验通过。随后检查结果、保存完整存档、重新试玩；更新游戏文件沿用「Lua 脚本 → 实机脚本同步」。
3. 「复制提示词给 AI」先提交草稿并保存当前完整存档。提示词给出工作区、存档、脚本位置，以及获取全部映射的方法：读存档 JSON 顶层 `controlGuidChanges` 的 `oldGuid`/`newGuid`，结合 `controlAsset`/`controlId` 和时间顺序核对。源码在 `assets.scripts[].source`，文件路径在 `.path`。任何规模都不依赖界面显示的前 20 项，不向聊天塞入数千行映射。首次未保存的工程先要求选存档路径。复制后在同步区域顶部展开可选取的完整文本，并回到该区域顶部；剪贴板不可用时也能直接手动复制，无须向下滚动寻找。
4. 用户把任务粘贴给自己当前项目的 AI。AI 从指定磁盘存档重新加载，处理内联源码、源文件和生成器映射，核验后仅确认已处理记录并保存。用户点「AI 已处理，重新载入存档」，再进入实机脚本同步。编辑器没有偷偷向某个 AI 服务发送数据。

WOO 的 `TemplateGuids` 配置表可使用全量替换。希望保留非索引数字、处理间接计算或生成器配置时，选择 AI 路径。没有未完成核对就可直接清空记录的第三个主按钮。

## 全量替换边界

`control-guid-lua.js` 按旧索引的十进制文本匹配完整连续数字段，不区分语法和用途，不在更长的数字串中切出子串。逐控件组合连续变更为初值→终值，再对原源码一次性应用；支持同批占用区间重叠，不串号。运行时 ID、图片 ID 或其他参数与旧索引相同也会被替换，这是用户选择此选项时明确展示的风险。除匹配文本外保留格式及换行。

此模式不计算十六进制、科学计数法或 `50+50` 等表达式的值，不遍历工程里未登记的模块和生成器。引用由这些方式产生时应选 AI。源码与项目文件不同、文件不可读取、映射身份有歧义等事务冲突仍拒绝整轮替换，保留待处理记录。

`controlGuidChanges[].scriptSignature` 继续作为修改索引当时的源码摘要保留，供 AI 核对；全量替换针对点击时的当前源码，不要求旧存档带此字段。已经手动更新过部分代码时，同值的新编号也可能被再次当作旧编号处理，需检查结果或使用 AI 语义同步。

## 宿主与文件事务

共享 Host 提供两个 patch：

```json
{ "op": "previewControlGuidSync", "expectedRevision": 15 }
{ "op": "syncControlGuidReferences", "planId": "预览返回的 id", "expectedRevision": 15 }
```

预览返回快照附加的 `controlGuidSyncPreview`；应用返回 `controlGuidSyncResult`。编辑器一次点击顺序完成预检与应用，不额外要求确认。Web、DSH、MCP 共用 Controller；纯 `createStudio()` 不提供文件同步操作。计划只在当前进程有效。AI 默认走语义同步，只有用户明确选择全量文本替换时才用这两个操作替代语义判断。

应用时重验完整存档与项目文件指纹，在工作区 `.qxqy-guid-sync-backups/<计划ID>/` 保存原存档、被改文件原内容，再替换文件并提交经过验证的新存档状态。错误时回滚已写文件，保留待处理记录；回滚失败明确返回备份位置。路径使用 Host 工作区边界，游戏目录不属于此步骤。不创建缺失的源文件，不覆盖与内联源码不同的源文件。尚未保存的新存档仍通过现有保存入口落盘。
